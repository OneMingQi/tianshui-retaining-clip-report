# 当前算法分析与改进路线

分析日期：2026-11-02。依据为本机发布包源码、原项目说明及本次小规模运行记录。以下改进是待实验验证的方案，不代表已经实现或已优于原方案。

## 1. 实际任务与目标任务

当前系统从三种型号的预抓取 USD 场景出发，回放关节轨迹，切换到固定末端姿态的笛卡尔插入，执行松手、归位，部分型号允许重夹。相机用于录像，控制器直接读取仿真物体位置。它是一个三型号、以平移偏差为主的接触插入验证平台。

目标系统是六型号、视觉观测不完整、存在位置和角度误差以及夹持滑移的真实柔顺装配。任务目标已知，主要难点是接触状态不可直接观测、误差与摩擦耦合、受限力下的对准，以及稳定松手。该问题适合分阶段控制和带历史的接触状态估计，无需把任务识别或语言模型放入实时闭环。

不能预设接触一定按“点→线→面”单向演化。实际可能出现多点接触、滑动、脱离、再次接触和楔紧；控制器首先需要识别的是“自由、可滑入、受阻、滑移、到位”等能指导动作的状态。

## 2. 当前算法组成

| 层次 | 当前实现 | 边界 |
|---|---|---|
| 任务调度 | 型号配置、预定义目标与轨迹 | 无在线目标识别需求 |
| 主控制 | ReplayInsertController 状态机、轨迹回放、IK、位置命令 | 非端到端 RL |
| 横向对准 | 物体位置误差 EMA、死区、限幅积分、型号偏置补偿 | 依赖仿真真值 |
| 轴向进给 | 滤波后的合力反馈到 Z 位移，叠加下压爬行项 | 简化导纳式外环；不是完整六维 M-D-K 导纳 |
| 解卡 | 圆周扰动、随机试探、卸力、部分重夹逻辑 | 大量人工参数，部分重试默认关闭 |
| SFT | 行为克隆：14 或 6 维输入，128×128 MLP，2 维 XY 增量 | 训练目标来自脚本动作 |
| 离线 RL | expectile V + Q + 优势加权行为回归，256×256 MLP | TD 目标不同于标准 IQL |
| 策略接入 | cart_descend 中 add 或 replace | 不控制姿态、抓持与松手动作 |
| 成功评估 | 物体位置误差、速度，结合控制器失败标志及回合质量门 | 没有完整的姿态/到位独立传感验证 |

14 维输入为 F(3)、T(3)、目标与物体位置误差(3)、物体与末端相对位置(3)、XY 误差差分(2)。它没有显式包含型号、装配阶段、前一指令或控制器积分状态，也没有历史窗口。

SFT 与离线 RL 在现有脚本中分别从数据训练；train_offline_rl.py 没有加载 SFT 权重。因此网页的“SFT→RL”不应直接理解为已经实现 SFT 初始化后再做 RL 微调。

## 3. 应先解决的实现与评估问题

### 3.1 行为动作不等于残差动作

fit_xy_model.py:52 和 train_offline_rl.py:44 使用相邻 ee_cmd 的差作为训练标签。controllers.py:594 附近先执行脚本修正，再在 add 模式叠加模型增量。模型学会脚本动作之后，再叠到脚本上，可能重复反馈、增加增益并引发过冲。降低 scale 可以缓解，却没有定义出真正的残差学习任务。

真正残差应满足 u = u_base + δu。若采用监督学习，标签需要是同一状态下专家动作与基线动作之差；只拥有基线自己的数据时，不能凭空从这些标签中得到更好的专家残差。可先采集人工/优化控制器纠正，或在仿真中用 RL 学习有界残差，并显式记录 u_base、δu、限幅后的实际 u。

### 3.2 当前离线 RL 不等于标准 IQL

train_offline_rl.py:117 使用 Q_target(s_next, π(s_next)) 构造 TD 目标；标准 IQL 使用 r + γ(1-d)V(s_next)。当前写法会评估离线数据分布之外的策略动作，失去标准 IQL 避免这类查询的重要特性。已有 expectile 和优势加权回归组件，不足以确认整个实现就是标准 IQL。

采样只保留 descend/cart_descend，D 全部为零，没有最终装配成功/失败事件；奖励主要是 XY 误差改善及较高合力的惩罚。它并没有完整优化“插到底、无卡滞、松手后保持到位”。应明确是接触阶段子任务，还是包含松手的完整任务，再正确处理成功终止、失败终止及时间截断；不能把所有切段都一概当终止，也不能始终不终止。

### 3.3 训练与部署状态不一致

训练用原始 obj_target 计算误差；controllers.py:517 在模型推理前加入 cart_xy_bias。lab2 的配置为 X +4 mm、Y +3.5 mm，lab3 为 X +2 mm，训练和部署的误差定义因此不同。应共用特征构造代码，把物理目标和控制补偿偏置分开表达。

训练同时包含 descend 和 cart_descend，推理主要在 cart_descend 调用；两段的动作来源不同。应统一策略作用区间，或明确把阶段输入策略。动作“每帧增量”还需要绑定采样周期，不能在更换控制频率后直接沿用数值。

### 3.4 六维力可测不代表任务可观测

纯力模型删除了物体真值输入，但外层脚本仍用真值计算 XY 归中、阶段切换、落座与松手引导。因此整个系统还不是纯力觉策略。

仅一帧六维力通常不足以唯一判断接触几何。未接触时许多位置偏差产生近似相同的力；接触时摩擦、刚度和夹持偏心也会造成歧义。应使用带有效性标记的视觉估计、运动反馈和一段力/动作历史。

### 3.5 数据与指标

训练会同时读取主目录和 explore 副本；副本被赋予不同 episode ID，可能跨训练/验证集泄漏。需按采集回合唯一 ID 或轨迹内容去重，再按回合、工况分组划分。不要把相邻帧或同回合副本当独立验证样本。

SFT 的动作 MAE 表示模仿误差；IQL 与行为动作的 MAE 也不能判断策略收益。最终要用闭环成功率、峰值/持续力、力矩、耗时、重试与滑移评估。当前质量力门在回合结束后计算，并不等价于实时安全保护。

原文档同 seed 30 次实验：脚本 26/30，14 维 RL add/0.5 为 22/30，纯力 RL add/0.5 为 18/30。这是发布者报告，本机尚未按此规模复验。本机各型号 1 次的模型 3/3 只证明可执行，不足以否定上述差距。现有证据支持“当前学习增强尚未显示优势”，不支持“RL 不适合”或“XY 动作空间已被证明达到上限”。

## 4. 推荐架构

任务配置/型号参数 → 多相机位姿估计与置信度 → 接触状态估计 → 分阶段导纳基线 + 有界学习修正 → 独立安全监督 → 机器人底层伺服。

视觉负责几何对准并提供置信度、时间戳；力负责接触约束和受力状态；学习模块补偿基线难以建模的误差。不要把三类信号简单做一个固定加权和。视觉失效时，应传播带增长不确定度的短时预测；只有处于已验证的接触与运动范围内才继续柔顺动作，否则回退或停止。

### 路线 A：分阶段、按型号调度的六维导纳（优先工程基线）

在槽口坐标系区分插入轴、横向轴与转动自由度。先验证坐标变换、工具/固定夹重力与偏心补偿，再构建 M_d δẍ + D_d δẋ + K_d δx = F_ext - F_ref 的导纳偏移模型，与名义位姿组合。符号、坐标和执行接口必须按设备定义验证。

自由接近、初接触、对准、插入、落座、卸载、松手使用不同的参考力、阻尼和进给限值。考虑真实角度偏差，在具备安全测量和姿态动作接口后逐步开放小范围转动柔顺，先控制与卡滞最相关的轴，而非一次开放任意六维探索。

六个已知型号可以先配置六组基础参数，再按阶段调度。跨型号共用同一固定参数并非必要目标。用低风险实验和贝叶斯优化/CMA-ES 调有限参数，也可能比当前 RL 更快获得收益；参数寻优仍需独立留出工况评估。

改变导纳参数需要限制变化率，并检查离散时间稳定性；若接触刚度和通信延迟变化明显，可加入能量/无源性监督。单纯约束 M、D、K 为正不能保证任意时变控制稳定。

### 路线 B：接触状态估计 + 有限恢复动作（优先解决卡滞与松手失败）

先用力、力矩、插入进度、命令与实际运动差、夹爪状态和持续时间建立带滞回的规则状态机。再比较 HMM、轻量时序分类器等方法能否提升接触状态识别。

有限动作库包括继续低速插入、卸力、抬升退出、重新对准、小范围姿态调整、稳定卸载后松手。重夹仅在夹具允许和有可靠目标估计时启用。优先用可解释规则选动作；数据充分后让高层策略选择动作及少量参数，底层仍由导纳执行。这能覆盖单纯 XY 增量无法修复的失败。

### 路线 C：带历史的小网络 + 真正的残差 RL（优先学习路线）

输入建议包括视觉位置/角度残差及置信度、补偿后力矩、末端速度、插入进度、基线动作、上一实际动作、阶段、型号/几何参数。先比较短窗口堆叠 MLP、TCN 和小 GRU，窗口长度由接触响应时标决定。初始可从约 0.2–0.5 秒历史试验，不能把该数值当通用最佳设置。

输出先限于小范围横向/相关姿态残差；后续可单独比较参考力或阻尼调节。初始残差为零，随接触状态和估计置信度门控；监督最终合成动作的位移、速度、加速度、力矩和工作空间。模型不确定度门控有助于降级，但不是安全证明。

只有离线日志时：修正标准 IQL，配合 BC 基线，明确真实残差标签与数据覆盖。能充分交互仿真时：可比较残差 PPO 或 SAC；PPO 适合批量并行采样，SAC 复用数据、样本效率通常更有吸引力。不能只因两张 GPU 就认定 PPO 最快，当前仿真吞吐需实际测量。

奖励使用插入进度、真实到位、姿态误差、超力/超力矩、卡滞时间与动作平滑，完整任务还应包含松手后保持到位。独立安全层不由奖励替代。

仿真训练可用带特权信息的 critic，部署 actor 只用真机可得观测，并加入摩擦、间隙、刚度、抓持变换、偏置、延时、掉帧和噪声随机化。随机化范围应来自测量；先做系统辨识，避免任意扩大范围把训练问题改变。

### 视觉建议

任务和型号已知，优先考虑工装标记/PnP、CAD 几何配准或轻量关键点网络。标记板/标定结构必须与真实槽口建立可信几何关系。双目提供深度约束，但窄间隙精度仍需实测。

多视角采用重投影误差、遮挡比例、时间戳和协方差进行剔除、加权或切换；在 SE(3) 上估计位姿，必要时用 EKF 或滑窗优化处理异步观测。共享标定误差使多个相机并不独立，不能简单平均并假定精度必然提高。交接时限制命令跳变。

### 其他候选算法

| 方法 | 合适条件 | 当前优先级 |
|---|---|---|
| 贝叶斯优化/CMA-ES 调参数 | 少量控制参数、可重复试验 | 高 |
| 局部模型预测控制/MPPI | 有辨识过的局部接触模型，需前瞻约束 | 中；先评估 Orin 计算预算 |
| CQL/TD3+BC 等离线 RL | 有足够覆盖的离线数据，作为对照 | 中；不能解决缺观测或动作定义问题 |
| Diffusion Policy/ACT | 有丰富高质量序列示范，需学习较长动作过程 | 后续；当前数据不足，接触段仍需高频反馈 |
| VLA | 任务语义、跨任务泛化价值大时 | 当前低；不针对本项目首要瓶颈 |

## 5. 实验路线与验收

1. 统一状态/动作时间定义、去重、训练/部署特征、IQL 目标与终止；不把这些修复混入算法优越性宣称。
2. 建立故障分类：入口错位、姿态卡滞、夹持滑移、松手带起、重夹推偏、感知失效。标明失败发生阶段。
3. 公平比较原脚本、分阶段导纳、导纳+恢复动作、导纳+历史残差学习。额外单独比较残差学习有/无历史、有/无视觉、有/无姿态动作，避免一次改变全部因素。
4. 以相同工况配对运行多随机种子；先每型号至少 30 回合作为初筛，再按效果与置信区间决定扩大规模。此数量不是高可靠性认证门槛。
5. 分别评估已知型号新工况、未知型号、视觉遮挡、角度误差和摩擦/刚度变化；保留不用于调参的最终测试集。相同 seed 不能替代保存实际扰动参数，跨机器物理仿真也不应假定逐帧确定。
6. 主指标是独立判据下松手后稳定装配成功率；同时报告每型号结果、95% 置信区间、峰值与持续力/力矩、耗时、重试数、滑移、异常退出以及控制周期延迟。
7. 真机以低速低力从单型号开始，对齐采样时钟与坐标、辨识摩擦和载荷、验证限力回退，再增加型号与扰动。仿真中的 150/350/500 N 参数不直接作为真实工件安全值。

建议的资源顺序：先把可解释控制基线和故障恢复做好，同时修正训练管线；有可信基线、有效数据和明确失败分布后，再引入历史状态下的有界残差学习。是否采用 RL，由它在相同安全约束下对成功率、受力和耗时的净收益决定。
